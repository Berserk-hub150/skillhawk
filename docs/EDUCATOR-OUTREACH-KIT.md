## Email to a professor or lecturer

**Subject:** Free browser-based AI Agent Security Lab for students

Hi,

I maintain SkillHawk, an open-source security scanner and hands-on lab focused on AI Agent Skills, `SKILL.md`, MCP configurations, and risky automation instructions.

I built a classroom-ready Security Lab where each student forks the repository, repairs intentionally unsafe agent instructions directly in GitHub, and gets automatic feedback from GitHub Actions. There is no local setup, Docker, API key, or AI service required for the core exercise.

The lab has 10 sequential levels covering remote execution, credential access, destructive commands, persistence, privilege escalation, outbound data transfer, prompt injection, dynamic shell execution, and related risks.

## What to send, and to whom

Prefer targeted outreach over mass posting. Good targets include:

- university lecturers teaching cybersecurity, secure software engineering, DevSecOps, software security, AI engineering, or applied LLM courses;
- university cybersecurity and computer-science clubs;
- CTF and security meetup organizers;
- coding bootcamps with secure-development modules;
- AI-agent / MCP community organizers;
- open-source mentoring programs looking for browser-first exercises.

Do not spam large generic lists. A short personalized first sentence explaining why the lab matches the recipient's course or group is more useful than sending the same message everywhere.

## Adoption signal to track

For each outreach batch, track only:

1. messages sent;
2. replies;
3. educators/organizers who say they will try the lab;
4. new forks during or shortly after a session;
5. learners reaching Level 1 and later levels.

This makes it possible to improve the pitch and onboarding based on actual use rather than raw impressions.
